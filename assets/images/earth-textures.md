The HOME globe serves these Three.js example textures locally:

- earth-surface.jpg: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
- earth-lights.png: https://threejs.org/examples/textures/planets/earth_lights_2048.png
- earth-ocean-mask.jpg: https://threejs.org/examples/textures/planets/earth_specular_2048.jpg

All three image files must travel with the website. The globe remains hidden until all three load. Run `python scripts/check_local_references.py` to check static JavaScript asset URLs as well as HTML and CSS references.
